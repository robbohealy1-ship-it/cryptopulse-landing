## 🔧 Optional Setup (When Ready)

### **Reddit API (5 minutes, FREE):**
1. Go to: https://www.reddit.com/prefs/apps
2. Create app
3. Add to .env:
   ```bash
   REDDIT_CLIENT_ID=your_id
   REDDIT_CLIENT_SECRET=your_secret
   REDDIT_USERNAME=your_username
   ```

### **Discord Webhooks (2 minutes, FREE):**
1. Join crypto Discord servers
2. Get webhooks from server settings
3. Add to .env:
   ```bash
   DISCORD_WEBHOOK_URLS=webhook1,webhook2
   ```
