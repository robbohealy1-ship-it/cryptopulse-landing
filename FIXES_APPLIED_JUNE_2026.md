### ✅ Fix #1: Forex Symbol Error Resolution
**File**: `src/engine/sniper_signal_engine.py`  
**Issue**: Sniper engine tried to fetch Forex symbols (EUR/USD, GBP/USD, etc.) from Binance scanner, which doesn't support Forex pairs  
**Error**: `binance does not have market symbol EUR/USD`

**Solution**: 
- Added market type check in `_analyze_symbol()`
- Sniper engine now skips Forex symbols (returns `None`)
- Forex signals handled exclusively by `ForexSignalEngine` with proper `ForexClient`

**Impact**: 
- ✅ No more Forex symbol errors in logs
- ✅ Cleaner error handling
- ✅ Forex signals still generated by dedicated Forex engine

**Code Change**:
```python
# Added check before fetching OHLCV
if market_type == MarketType.FOREX:
    # Forex symbols need ForexClient, not Binance scanner
    # Skip sniper analysis for Forex (let forex_signal_engine handle it)
    return None
```

### ✅ Fix #2: NewsAPI Cache Extension
**File**: `src/analysis/enhanced_context_engine.py`  
**Issue**: NewsAPI rate limits (100 requests/24h) still being hit occasionally

**Impact**:
- ✅ 50% reduction in NewsAPI calls
- ✅ Fewer rate limit errors

**Code Change**:
