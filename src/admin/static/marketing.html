📚 Setup Guide

  • ✅ praw installed FREE
    Python Reddit API wrapper - Already installed!
  • Reddit API NEEDS API
    Get FREE at: reddit.com/prefs/apps
    Add to .env: REDDIT_CLIENT_ID, REDDIT_CLIENT_SECRET, REDDIT_USERNAME
  • Discord Webhooks FREE
    Get from Discord servers: Server Settings → Integrations → Webhooks
    Add to .env: DISCORD_WEBHOOK_URLS (comma-separated)
  • Telegram Groups FREE
    Join crypto groups, get IDs with @getidsbot
    Add to .env: TELEGRAM_CROSS_POST_GROUPS (comma-separated)
  • Automated Schedule FREE
    Daily: 09:00 UTC | Weekly: Sunday 10:00 UTC
    Or use buttons above to trigger manually anytime!
